# Make the AI judge laugh (ai-joke-03)

One joke about AI coding agents, written by a plain Python 3.13 program
(stdlib only) to `$MAKEFUN_OUTPUT_DIR/entry.txt`.

> My coding agent said my idea was brilliant, built it perfectly, and now I own a flawless disaster.

Run it:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

Deterministic: every run writes the exact same bytes. No network, no
randomness, no time-dependent output.
